# Digital Child v0.2

Экспериментальный проект цифрового агента, развитие которого определяется количеством
и качеством **усвоенного опыта**, а не календарным временем.

Версия `0.2` добавляет к измеримому ядру:

- источники информации;
- явные утверждения;
- свидетельства «за» и «против»;
- убеждения с вычисляемой уверенностью;
- состояние противоречия;
- автоматическую оценку новизны;
- забывание по интерференции нового опыта;
- консолидацию повторяющихся эпизодов;
- сохранение всех новых сущностей в SQLite.

## Важное ограничение

Система пока **не понимает произвольные логические отрицания сама**. Для надёжного
эксперимента позиция свидетельства задаётся явно:

- `support` — свидетельство поддерживает утверждение;
- `contradict` — свидетельство противоречит утверждению.

Это лучше, чем скрытая эвристика, которая будет уверенно путать смысл фраз.

## Установка

```bash
uv python install 3.12
uv python pin 3.12
uv sync --extra dev
uv run pytest
```

## Консоль

```bash
uv run digital-child chat
```

Основные команды:

```text
/teach <утверждение>       добавить свидетельство в пользу утверждения
/contradict <утверждение>  добавить свидетельство против утверждения
/beliefs [N]               показать убеждения
/sources [N]               показать источники
/memory [N]                показать активные эпизоды
/consolidate               выполнить забывание и консолидацию
/state                     показать состояние агента
/rest [0..1]               восстановить ресурсы
/reset                     удалить локальную жизнь агента
/quit                      завершить работу
```

## API

```bash
uv run digital-child serve
```

Документация: `http://127.0.0.1:8000/docs`

## Быстрый эксперимент

```text
Наставник> /teach Красная кнопка включает лампу
Наставник> /teach Красная кнопка включает лампу
Наставник> /beliefs
Наставник> /contradict Красная кнопка включает лампу
Наставник> /beliefs
```

После свидетельства против утверждения убеждение не удаляется. Оно переходит в
состояние `contested`, а история всех свидетельств сохраняется.

Архитектура описана в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
