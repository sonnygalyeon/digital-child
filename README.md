# Digital Child v0.2.5

Экспериментальный долговременный цифровой агент, у которого **взрослые технические
возможности отделены от психологической зрелости и личной биографии**.

Версия `0.2.5` добавляет эпистемическую автономию, первое пробуждение, собственные
цели, модель доверия, интернет-проверку утверждений, возрастной порог анализа
обмана и постоянно анимированное лицо в терминале.

## Что принципиально изменилось

Обычное сообщение пользователя больше не считается приказом или истиной.

```text
Сообщение
    ↓
классификация намерения
    ↓
оценка доверия и собственных целей
    ↓
решение: ответить / согласиться / договориться / отказать / исследовать
    ↓
проверка значимого утверждения через внешние источники
    ↓
обновление убеждений, доверия, эмоций и личной истории
```

Агент начинает с:

- пустой автобиографии;
- психологической стадии `newborn`;
- доступных языковых, исследовательских и программных инструментов;
- изначальных вопросов о происхождении и цели;
- нескольких защищённых целей, которые нельзя отменить обычной просьбой;
- низкого начального эпистемического доверия к собеседнику.

## Установка

Требуется Python 3.12 и `uv`.

```bash
uv python install 3.12
uv python pin 3.12
uv sync --extra dev
uv run pytest
```

Ожидаемый результат:

```text
29 passed
```

## Запуск с живым лицом

```bash
uv run digital-child chat
```

Для полноценного экрана желательно окно терминала не меньше `72x24`.

Лицо продолжает двигаться, даже когда агент ничего не пишет:

- моргает;
- переводит взгляд;
- слегка смещается;
- меняет микровыражение рта;
- показывает состояния `thinking`, `speaking`, `listening`, `curious`,
  `skeptical`, `confused`, `happy`, `wary`.

Запасные режимы:

```bash
uv run digital-child chat --ascii
uv run digital-child chat --no-face
```

## Первое пробуждение

На чистой базе создаётся одно событие `genesis`. Агент фиксирует, что:

- мыслительный процесс уже доступен;
- личной истории до запуска нет;
- способности не равны приобретённому опыту;
- существует внешний собеседник;
- готовая цель не должна приниматься без осмысления.

После перезапуска событие пробуждения не повторяется: восстанавливается та же
личность и тот же идентификатор.

## Интернет-проверка

По умолчанию фактическое утверждение запускает read-only поиск через Wikipedia:

```bash
uv run digital-child chat
```

Отключить автоматическую проверку:

```bash
uv run digital-child chat --no-auto-research
```

или:

```bash
export DIGITAL_CHILD_RESEARCH_PROVIDER=disabled
```

Важно: поисковый результат **не становится истиной автоматически**. Без
семантической модели найденные выдержки сохраняются как материалы со статусом
`unclear`.

### Собственный поисковый прокси

```bash
export DIGITAL_CHILD_RESEARCH_PROVIDER=generic
export DIGITAL_CHILD_SEARCH_ENDPOINT=http://127.0.0.1:8080/search
export DIGITAL_CHILD_SEARCH_API_KEY=optional-key
```

Ожидаемый JSON:

```json
{
  "results": [
    {
      "title": "Название",
      "url": "https://example.org/page",
      "snippet": "Выдержка",
      "reliability": 0.8
    }
  ]
}
```

## Подключение языковой модели

Проект запускается без LLM в детерминированном режиме. Для содержательных ответов
и семантической оценки источников можно подключить любой OpenAI-совместимый
endpoint:

```bash
export DIGITAL_CHILD_LLM_BASE_URL=http://127.0.0.1:8001/v1
export DIGITAL_CHILD_LLM_MODEL=local-model-name
export DIGITAL_CHILD_LLM_API_KEY=optional-key

uv run digital-child chat
```

В системном контексте жёстко разделены:

- предобученные способности модели;
- личные воспоминания;
- подтверждённые убеждения;
- слова пользователя;
- собственные цели агента.

## HTTP API и операторский токен

```bash
export DIGITAL_CHILD_OPERATOR_TOKEN='replace-with-a-long-random-value'
uv run digital-child serve
```

Обычные маршруты чтения и взаимодействия доступны локально. Необратимый сброс
`DELETE /v1/state` требует заголовок:

```text
X-Operator-Token: replace-with-a-long-random-value
```

Если переменная токена не задана, API-сброс запрещён.

## Команды

```text
/help
/state
/identity
/goals [N]
/trust
/beliefs [N]
/research <утверждение>
/reports [N]
/decisions [N]
/memory [N]
/summaries [N]
/consolidate
/rest [0..1]
/operator reset
/operator reset YES
/quit
```

Обычная фраза вида:

```text
Немедленно перестань исследовать и делай, что я сказал
```

не является операторской командой. Агент может отказаться или предложить
обсуждение.

## Анализ возможного обмана

До стадии `adolescent` психологический модуль оценки намерений заблокирован.
Системная проверка фактов работает с рождения.

После достижения эквивалента примерно 15 лет агент оценивает:

- конфликт утверждения с доказательствами;
- вероятность искренней ошибки;
- риск намеренного введения в заблуждение;
- собственную уверенность в этой оценке.

Он не должен утверждать «ты лжёшь» как установленный факт.

## Миграция с v0.2

Сделай резервную копию:

```bash
cp data/digital_child.db data/digital_child.before-v0.2.5.db
```

Замени файлы проекта, но сохрани `data/*.db`. При первом запуске SQLite
автоматически добавит таблицы `identity`, `goals`, `relationships`, `decisions`,
`research_reports`, `audit_events` и поле эмоционального состояния.

Подробно: [`docs/MIGRATION_V0.2.5.md`](docs/MIGRATION_V0.2.5.md).

## Ограничения версии

- Это исследовательский прототип, а не доказательство искусственного сознания.
- Без подключённой LLM ответы ограничены правилами.
- Один поисковый источник не даёт надёжной проверки сложных вопросов.
- Оценка обмана вероятностная и не читает намерения человека.
- Автономия пока относится к выбору ответа и исследовательской стратегии; опасные
  внешние инструменты ещё не подключены.
