# Digital Child

`Digital Child` — минимальное измеримое ядро развивающегося цифрового агента.

На этом этапе проект **не подключает LLM**. Цель первой версии — проверить, что агент:

- получает наблюдения;
- превращает их в измеряемый развивающий опыт `DEU`;
- развивается по нескольким направлениям, а не по одному общему счётчику;
- изменяет внимание, энергию и любопытство;
- сохраняет эпизоды и состояние между перезапусками;
- не переходит на новую стадию только из-за большого объёма информации одной категории.

## Требования

- macOS, Linux или Windows;
- Python 3.12;
- `uv`.

## Установка

```bash
uv python install 3.12
uv python pin 3.12
uv sync --extra dev
```

## Проверка

```bash
uv run pytest
uv run python -m compileall -q src
```

## Консоль наставника

```bash
uv run digital-child chat
```

Команды:

- `/help` — справка;
- `/state` — текущее состояние и развитие;
- `/memory` — последние эпизоды;
- `/rest [0..1]` — восстановление энергии;
- `/reset` — удалить память и начать заново;
- `/quit` — выход.

## HTTP API

```bash
uv run digital-child serve
```

После запуска:

- API: `http://127.0.0.1:8000`;
- Swagger: `http://127.0.0.1:8000/docs`.

## Что такое DEU

`DEU` — Developmental Experience Unit, единица усвоенного развивающего опыта.

В первой версии:

```text
quality =
    novelty
  × attention
  × comprehension
  × reliability
  × integration
  × (0.5 + 0.5 × practical_confirmation)

DEU = raw_units × quality
```

Большой объём сырой информации не гарантирует развитие. Информация должна быть новой,
понятой, достоверной и встроенной в прежний опыт.

Подробности находятся в `docs/ARCHITECTURE.md` и `docs/ROADMAP.md`.
