# Установка на чистую Windows

Установщик использует встроенный Windows PowerShell 5.1. Python, Git, uv, winget,
Ollama и Docker заранее устанавливать не требуется. Нужны Windows 10 22H2 или
Windows 11 x64, доступ в интернет и свободное место для приложения и модели.

## Первый запуск

1. [Скачайте ZIP проекта](https://github.com/sonnygalyeon/digital-child/archive/refs/heads/developmental-psychology-windows.zip).
2. Распакуйте архив в обычный каталог. Запуск непосредственно внутри ZIP не поддерживается.
3. Дважды щёлкните `install_windows.cmd`.
4. На вопрос «Куда установить приложение» укажите полный путь или нажмите Enter.
5. На вопрос «Куда скачать и хранить модель» укажите полный путь или нажмите Enter.
6. Дождитесь загрузки и установки. Откроется окно со сферой и чатом.

Пример выбора:

```text
Приложение: C:\Apps\DigitalChild
Модель:     D:\AI\DigitalChildModels
```

Пути с пробелами и русскими буквами поддерживаются. По умолчанию приложение
устанавливается в распакованный каталог проекта, а модели — в его подкаталог `models`.
Если запущен только отдельно скачанный `.ps1`, приложение по умолчанию размещается
в `%LOCALAPPDATA%\DigitalChild`; исходники автоматически загружаются с GitHub.

Установщик скачивает переносимые uv и Ollama из официальных GitHub Releases,
проверяет SHA256 архивов, устанавливает Python 3.12 и зависимости GUI из `uv.lock`.
По умолчанию загружается `qwen3:4b-instruct`; из неё создаётся локальный профиль
`digital-child-fast` с контекстом 4 096 токенов и ограничением ответа 512 токенами.

Размер весов этой модели — примерно 2,5 ГБ. Дополнительно нужны место для Python,
Qt, Ollama и временных архивов. Рекомендуется оставить не менее 15 ГБ на диске
приложения и 5 ГБ на диске моделей; если это один диск, суммируйте запас.
Скорость загрузки и генерации зависит от интернета и компьютера.

При отсутствии библиотек Microsoft Visual C++ установщик скачает официальный
пакет Microsoft, проверит его подпись и запустит установку. Windows может показать
запрос администратора именно для системных библиотек. Основные файлы размещаются
в выбранных каталогах; глобальный PATH и постоянная политика PowerShell не меняются.

Источники компонентов:
[uv](https://docs.astral.sh/uv/getting-started/installation/),
[Ollama Windows](https://docs.ollama.com/windows),
[Qwen3 4B Instruct](https://ollama.com/library/qwen3:4b-instruct),
[Microsoft Visual C++](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

## Последующие запуски

Используйте ярлык **Digital Child** на рабочем столе. Он запускает сохранённую Ollama
с выбранным каталогом моделей, ожидает готовности локального API и открывает GUI.
После перезагрузки Windows повторная установка не требуется.

Альтернатива: `start_windows.cmd` в каталоге установленного приложения.
Для запуска из PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\windows\start_desktop.ps1
```

Этот запуск не скачивает компоненты заново. Ollama остаётся локальным фоновым
процессом и может использоваться при повторном открытии окна. Автозапуск при входе
в Windows и Windows-служба не создаются.

## Установка с заданными параметрами

Интерактивный выбор можно заменить аргументами:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install_windows.ps1 `
  -InstallDir "C:\Apps\DigitalChild" `
  -ModelDirectory "D:\AI\Models" `
  -NoLaunch
```

Другие параметры: `-NoShortcut`, `-BaseModel "qwen3:4b-instruct"`, `-Port 11535`.
По умолчанию используется порт `11534`, чтобы не мешать обычной Ollama на `11434`.
Сервер привязан к `127.0.0.1`; LAN-доступ и правило firewall не создаются.
Если порт занят сторонним процессом, установка предложит выбрать другой порт;
сторонний сервер не останавливается и не используется для загрузки в неверный каталог.

## Где что хранится

| Каталог / файл | Содержание |
| --- | --- |
| Выбранный каталог приложения | исходники, инструкции и запуск |
| `.runtime` | uv, Python, переносимая Ollama, кэш, журналы и скрытый launcher |
| `.venv` | окружение Python и Qt |
| `.desktop-install.json` | каталог модели, локальный порт и путь Ollama |
| `.env` | настройки агента и подключения к локальной модели |
| `data\digital_child.db` | личность, опыт, память, отношения и история |
| Выбранный каталог модели | реальные `blobs` и `manifests` Ollama |

`OLLAMA_MODELS` передаётся запускаемому серверу, поэтому веса действительно размещаются
в выбранном каталоге. Настройка не меняет расположение моделей сторонней Ollama.
Локальные веса, окружения, настройки и память исключены из Git.

## Повторная установка и перенос личности

Повторная установка сохраняет базу личности и не копирует чужой `.env` или базу из
исходного ZIP. Она меняет три параметра LLM в существующем `.env` для локального
подключения, сохраняя остальные настройки. Исходный `.env` один раз копируется
в `.env.windows-backup`.

Для повторной установки используйте тот же каталог приложения. Сохранённый каталог
моделей предлагается по умолчанию; загруженные слои модели используются повторно.
Перед повторной установкой закройте окно агента.
После неудачной первой загрузки выберите тот же каталог модели для продолжения.
Не меняйте каталог приложения простым переносом `.venv`: установите окружение в новом
месте и отдельно перенесите базу личности.

Для переноса с другого компьютера закройте агент и скопируйте его SQLite-базу
в `data\digital_child.db` установленного приложения. Это переносит того же субъекта,
включая темперамент и историю развития.

Чтобы сменить каталог модели, закройте окно и повторите установку с новым путём.
Старые веса автоматически не удаляются; другой каталог заполняется выбранной моделью.
Установщик перезапускает только собственный сервер при изменении своего каталога или порта.

## Если установка прервалась

- Повторите `install_windows.cmd` с теми же каталогами. Загрузка слоёв модели может продолжиться.
- Если порт занят, передайте другой `-Port`.
- Журнал сервера: `.runtime\logs\ollama-error.log`.
- Ошибка запуска ярлыка отображается отдельным сообщением; `start_windows.cmd` оставляет её в консоли.
- Для работы ускорения GPU нужны подходящие драйверы; без ускорения скорость на CPU ниже.

Установщик и launcher проверены статическим разбором PowerShell. Полная установка
и запуск на чистой Windows здесь не выполнялись. Тесты не запускались по запросу пользователя.
