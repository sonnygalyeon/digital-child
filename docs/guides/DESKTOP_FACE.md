# Визуализация сферы

Человеческое лицо заменено слоистой эмоциональной сферой. Основной интерфейс теперь
объединяет сферу и диалог в одном окне:

```bash
uv sync --extra desktop
uv run digital-child desktop
```

Для терминального режима сохранено необязательное отдельное окно той же сферы:

```bash
uv run digital-child chat
uv run digital-child face
```

`chat --no-face-window` отключает отдельное окно. Его закрытие не завершает терминальный
агент. Контроллер передаёт параметры `FaceState` через локальный `multiprocessing.Pipe`.

Сфера отображает семь прозрачных оболочек, устойчивое ядро, световые ленты и частицы.
Любопытство, возбуждение, уверенность, растерянность, доверие и усталость меняют
движение и свет. Переходы плавные, анимация независима от скорости LLM.

Установка на Windows, карта реакций и разделение процессов описаны в
[DESKTOP_APP.md](DESKTOP_APP.md).
