# Отдельное окно лица

## Почему лицо вынесено из терминала

`curses` одновременно перерисовывал лицо, журнал и поле ввода. На некоторых терминалах
это ломало Unicode-ввод и усложняло потоковый вывод. Теперь терминал и лицо работают
независимо.

## Технология

- PySide6 / Qt Widgets;
- отдельный процесс через `multiprocessing` со способом запуска `spawn`;
- локальный `Pipe`, без сетевого порта;
- векторная отрисовка `QPainter`;
- таймер анимации 60 FPS.

## Idle-поведение

Даже при отсутствии запросов лицо продолжает:

- моргать через неравные интервалы;
- плавно переводить взгляд;
- слегка двигать головой;
- имитировать дыхание;
- изменять яркость акцентных элементов;
- делать микродвижения рта.

## Эмоциональные состояния

Поддерживаются:

- neutral;
- curious;
- skeptical;
- confused;
- happy;
- thinking;
- listening;
- speaking;
- wary.

Лицо получает не готовые изображения, а численные значения эмоций: доверие,
любопытство, растерянность, усталость, возбуждение и валентность.

## Запуск

```bash
uv sync --extra desktop
uv run digital-child face
```

Закрытие окна лица не завершает агента. Терминальный чат продолжит работу.
