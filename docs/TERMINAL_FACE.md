# Терминальное лицо

Лицо является отдельным представлением эмоционального состояния, а не источником
логики.

## Непрерывные idle-эффекты

- blink: короткое моргание примерно раз в несколько циклов;
- pupil drift: редкие движения взгляда;
- head float: смещение на один терминальный символ;
- micro mouth: едва заметное изменение рта;
- expression override: `thinking`, `speaking`, `listening` во время активности.

## Потоки

Обработка запроса выполняется в рабочем потоке. Главный поток продолжает
перерисовывать экран. Это предотвращает застывание лица при сетевом поиске или
ответе LLM.

## Режимы

```bash
uv run digital-child chat          # Unicode + cyan curses UI
uv run digital-child chat --ascii  # совместимый ASCII
uv run digital-child chat --no-face
```

Минимальный размер окна: `72x24`.
