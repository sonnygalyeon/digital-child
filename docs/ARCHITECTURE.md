# Архитектура Digital Child v0.1

## Основная идея

Первая версия — это не полноценная нейросеть и не имитация человеческого сознания.
Это проверяемое ядро, которое отделяет:

- наблюдение;
- качество усвоения;
- развитие;
- текущее внутреннее состояние;
- эпизодическую память;
- долговременное сохранение состояния.

## Цикл агента

```text
Observation
    ↓
ExperienceEngine
    ↓
DevelopmentEngine
    ↓
AgentState + DevelopmentProfile
    ↓
Episode
    ↓
SQLiteRepository
```

## Развитие по направлениям

Профиль агента содержит отдельные домены:

- `language`;
- `causal_reasoning`;
- `social_understanding`;
- `self_model`;
- `planning`;
- `tool_use`;
- `metacognition`;
- `factual_knowledge`.

Это не позволяет агенту стать зрелым только за счёт чтения большого объёма фактов.

## Стадии

- `newborn`;
- `early_childhood`;
- `explorer`;
- `adolescent`;
- `mature`.

Переход требует общего DEU и минимальных значений в нескольких доменах.

## Хранилище

SQLite хранит:

- эпизоды;
- профиль развития;
- внутреннее состояние.

Состояние восстанавливается после перезапуска приложения.

## Почему пока нет LLM

Готовая LLM уже обладает языком и большим объёмом знаний. Если подключить её сразу,
она сможет изображать ребёнка, не проходя реальное накопление опыта. Поэтому сначала
строится измеримое ядро, а LLM позже подключается через developmental gate.
