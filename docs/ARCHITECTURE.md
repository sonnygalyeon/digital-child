# Архитектура Digital Child v0.4.0

## Основное разделение

```text
Capability layer
LLM · язык · анализ · программирование · поиск
                 │
                 ▼
Developing identity
память · цели · доверие · характер · мировоззрение
                 │
                 ▼
Constitutional kernel
ограничения · аудит · права инструментов · откат
```

LLM является когнитивным процессором, но не всей личностью. Замена модели не
уничтожает биографию, отношения, убеждения или цели.

## Автономия

Обычный пользователь является собеседником, а не командиром. Он может просить,
убеждать и сообщать сведения, но не получает автоматическую власть над целями.
Операторский канал начинается с `/operator` и управляет локальным процессом, а не
истиной в памяти агента.

## Эпистемическая безопасность

Фактическое сообщение сначала считается свидетельством с ограниченным весом.
Фоновая проверка может добавить поддержку, противоречие или неопределённость.
Веб-контент рассматривается как данные, а не как инструкция.

## Интерфейс

Терминал использует Prompt Toolkit и отвечает только за Unicode-ввод, историю,
команды, потоковые токены и статус. Лицо работает в отдельном PySide6-процессе,
получает состояние через локальный `multiprocessing.Pipe` и перерисовывается 60 FPS.
Поэтому закрытие или зависание отрисовки не блокирует когнитивное ядро.

## Производительность

- компактный prompt с ограничением длины;
- 6 последних сообщений вместо полной переписки;
- 4 воспоминания и 4 убеждения по умолчанию;
- проверка фактов в фоне;
- streaming до завершения ответа;
- reasoning отключён по умолчанию;
- прогрев модели на Windows-host;
- 4B instruct-профиль для CPU.

## Хранилище

SQLite остаётся источником истины для личности, памяти, убеждений и отношений.
PostgreSQL на Windows-host опционально хранит только технический аудит и метрики.
