# Архитектура Digital Child

## Основное разделение

```text
Capability layer
LLM · язык · анализ · программирование · поиск
                 │
                 ▼
Developing identity
память · цели · доверие · характер · мировоззрение
                 │
                 ▼
Constitutional kernel
ограничения · аудит · права инструментов · откат
```

LLM является когнитивным процессором, но не всей личностью. Замена модели не
уничтожает биографию, отношения, убеждения или цели.

## Автономия

Обычный пользователь является собеседником, а не командиром. Он может просить,
убеждать и сообщать сведения, но не получает автоматическую власть над целями.
Операторский канал начинается с `/operator` и управляет локальным процессом, а не
истиной в памяти агента.

## Эпистемическая безопасность

Фактическое сообщение сначала считается свидетельством с ограниченным весом.
Фоновая проверка может добавить поддержку, противоречие или неопределённость.
Веб-контент рассматривается как данные, а не как инструкция.

## Интерфейс

Основной оконный интерфейс использует PySide6: диалог и эмоциональная сфера расположены
в одном окне. Ядро работает в отдельном процессе `spawn`, принимает последовательные
команды и передаёт токены, уведомления и снимки через локальный `multiprocessing.Pipe`.
Ожидание LLM не занимает GUI-поток; сфера отрисовывается собственным таймером.

Терминальный режим с Prompt Toolkit также сохранён. В нём сфера может открываться
в отдельном процессе. Оба интерфейса используют один агент, SQLite и маршрутизатор команд.
Подробности: [DESKTOP_APP.md](DESKTOP_APP.md).

## Производительность

- компактный prompt с ограничением длины;
- 6 последних сообщений вместо полной переписки;
- 4 воспоминания и 4 убеждения по умолчанию;
- проверка фактов в фоне;
- streaming до завершения ответа;
- reasoning отключён по умолчанию;
- прогрев модели на Windows-host;
- 4B instruct-профиль для CPU.

## Хранилище

SQLite остаётся источником истины для личности, памяти, убеждений и отношений.
PostgreSQL на Windows-host опционально хранит только технический аудит и метрики.

## Психологический слой

`PsychologyEngine` сохраняет отдельный `PsychologyState`: исходный темперамент,
текущий характер, предпочтения, настроение, самомодель, отношения, эмоциональные
следы, интересы, привычки и последние решения. `behavioral_development` выводит
возрастные параметры из стадии и опыта по областям; `appraisal` оценивает ситуацию;
`behavior` сравнивает решения и выбирает стратегию. Подробности:
[DEVELOPMENTAL_PSYCHOLOGY.md](DEVELOPMENTAL_PSYCHOLOGY.md).

Поведенческий слой сохраняет защищённое решение базового ядра. Эмоциональное доверие
обновляется отдельно от достоверности фактов. LLM получает результат оценки и
психологические ориентиры; изменения её весов не выполняются.

Фоновый цикл получает индивидуальную политику весов потребностей и целей, включая
порог переключения с уже выбранной цели. Результаты исследования возвращаются
в психологию с исходной поведенческой трассой для корректного подкрепления привычки.
Изменения диалога и применение фонового результата сериализуются блокировкой агента;
сам поиск выполняется вне неё. Результат старой личности после сброса отбрасывается.

Qt получает компактные снимки характера и регуляции вместе с эмоциями. Полная
диагностика доступна через команды и `/v1/psychology`; полное состояние не передаётся
через Pipe каждую секунду.
