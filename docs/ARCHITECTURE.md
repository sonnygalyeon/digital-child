# Архитектура Digital Child v0.2.5

## Основное разделение

```text
Capability layer
язык · анализ · программирование · поиск
                 │
                 ▼
Developing identity
память · цели · доверие · характер · мировоззрение
                 │
                 ▼
Constitutional kernel
необратимые ограничения · аудит · границы инструментов
```

Готовая LLM является когнитивным процессором, но не всей личностью. Замена модели
не должна уничтожать биографию, отношения, убеждения и цели.

## Цикл взаимодействия


## Автономия

Нормальный пользователь имеет роль собеседника. Он может предлагать, спрашивать,
убеждать и сообщать сведения, но не получает автоматическую власть над целями.

Явный операторский канал начинается с `/operator` и предназначен только для
управления локальным процессом. Даже он не записывает утверждения напрямую как
истину.

## Эпистемическая безопасность

Каждое фактическое сообщение человека сначала рассматривается как свидетельство
с ограниченным весом. Проверка может добавить поддерживающие, противоречащие или
неясные свидетельства.

```text
claim
  ├── testimony from person
  ├── external source A
  ├── external source B
  └── practical confirmation
          ↓
weighted confidence + status
```

## Доверие

У каждого человека отдельно хранятся:

- знакомство;
- эмоциональное доверие;
- эпистемическое доверие;
- риск обмана;
- число подтверждённых и опровергнутых сообщений;
- авторитет по областям.

Симпатия не равна компетентности.

## Развитие анализа обмана

Защитный слой не принимает непроверенные факты с самого рождения. Более сложное
рассуждение о мотивах собеседника открывается только при стадии `adolescent` и
достаточном опыте метакогниции и социального понимания.

## Терминальное лицо

`TerminalFaceApp` использует `curses` и отдельный рабочий поток:

```text
UI thread:      redraw 12 FPS + keyboard input
Worker thread:  research / LLM / decision cycle
```

Поэтому моргание, движение взгляда и другие idle-эффекты продолжаются во время
ожидания сети и генерации ответа.
